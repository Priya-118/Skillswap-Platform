# Skillswap-Platform
A backend-driven Skill Swap platform that enables users to exchange skills without monetary transactions. Built using RESTful APIs to manage user authentication, skill listings, match requests, and reviews. Implements role-based access, data validation, and scalable database schemas to support secure and efficient peer-to-peer interactions.
# SkillSwap Platform

## 🛠 Tech Stack
- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- Passport.js
- EJS
- Render (Deployment)

## 🔐 Features
- User authentication
- Skill listing
- Request system
- Session management

## ⚙️ Installation (Local Setup)
1. Clone repo
2. Add .env file
3. Run npm install
4. Run npm start
